# 图片提示词与透明度处理

## 编译

运行：

```bash
python3 scripts/compile_prompts.py \
  --style 2 \
  --reactions '🚲,🚗,🎉,😭,💪,😎,🤔,🤩,🍕' \
  --output-dir /absolute/path/to/job/prompts
```

`--style` 接受 1–36、两位 ID、slug 或完整中文名。`--reactions` 必须解析为九项；逗号、中文逗号、换行和竖线都可作分隔符。若用户给的是一句主题说明，先在对话中整理为九项并获得确认。

输出：

- `image-prompt.txt`：用于参考图生成统一纯绿底九宫格 PNG。
- `video-prompt.template.txt`：尚未选择幕布色时的模板。
- `prompt-plan.json`：风格、九项内容和模板版本。

`prepare_sheet.py` 选择实际幕布色后，可用 `compile_prompts.py --screen-report ...` 重新生成最终 `video-prompt.txt`。

## 纯色底优先策略（当前默认）

1. 当前不要让 Codex/ImageGen 生成透明图。首次生成直接使用不透明纯绿色 `#00FF00`（RGB `0,255,0`）背景，以缩短生成和失败重试时间。
2. 背景必须单色、平坦、无纹理、无渐变，并与画布四边和所有格间空白连通。人物及其必要元素不能越格。
3. `prepare_sheet.py` 只移除与画面边缘连通且接近检测背景色的区域，再检查真实 Alpha、透明间隔和每格非空；它不会全局删除人物内部碰巧相同的颜色。
4. 棋盘格、渐变、场景、纹理底板、阴影或边缘不一致时停止并重新生成。不要用阈值硬抠复杂场景。
5. 纯绿只用于生成源图。转换为 Alpha 后，视频幕布仍根据前景像素从绿、蓝、洋红、白中动态选择，不能默认沿用绿色。

这是兼容当前 Codex 图像生成能力的临时默认策略。等内置生成器能稳定返回真实 Alpha 后，应同时更新 `scripts/compile_prompts.py`、`scripts/compile_keypose_plan.py`、本节与相应测试，再将默认切回透明底；在此之前不要仅靠修改提示词绕过本地处理。

## 冲突处理

透明输出契约高于风格习惯。以下内容始终禁止出现在人物外缘或格子背景：白色切边、黑色外描边、彩色描边、光晕、投影、半透明贴纸边、卡片底、窗口底板。允许人物内部的原生线稿、材质纹理和为表达反应所需的小型符号，但必须留在本格内。
